# 🧸 소소하고 포근한 감성 다이어리 (mydiary)

> 언제 어디서나 나의 일상을 포근하게 기록하고, 다른 사람들과 소소한 이야기를 나누며, 깃허브로 영구 보존할 수 있는 커스텀 감성 다이어리 웹 애플리케이션입니다. ☁️

---

## 📌 1. 프로젝트 소개 (About)

* **개발 배경**: 기존 다이어리 앱들의 단조로운 디자인과 데이터 백업 부재의 아쉬움을 해결하기 위해 개발되었습니다. 11가지의 다채로운 테마와 감성적인 UI를 제공하고, SQLite3 및 GitHub API 연동을 통해 데이터베이스를 저장소와 자동 동기화함으로써 소중한 기록을 영구 보존할 수 있습니다.
* **주요 타겟**: 나만의 감성을 예쁘게 기록하고 싶고, 일정과 디데이를 한눈에 관리하며, 소소하게 일상을 공유하고 싶은 사용자들

---

## 📖 2. 사용법 (User Guide)

1. **회원가입 및 로그인**
   * 앱 실행 후 [회원가입] 탭에서 아이디, 비밀번호, 닉네임, 생년월일(선택)을 입력해 계정을 생성한 뒤 로그인합니다.
2. **프로필 및 테마 꾸미기**
   * 사이드바의 **[⚙️ 정보설정]**에서 닉네임, 한 줄 상태메시지, 프로필 이모티콘을 언제든지 변경할 수 있습니다.
   * **[🎨 테마관리]**에서 11가지 감성 테마 중 하나를 고르고, 포인트 메인 색상과 서브 색상을 직접 지정해 나만의 다이어리를 디자인합니다.
3. **비밀일기 & 공개일기 작성**
   * **🔒 비밀일기**: 달력에서 원하는 날짜를 클릭하면 노트 에디터로 이동합니다. 오늘의 감정과 일기 내용, 오늘의 질문 답변을 적고 `🔒 나만 보기`로 저장하면 나만의 비밀 달력에 감정 이모지가 표시됩니다.
   * **🌐 공개일기**: 일기를 작성할 때 `🌐 전체 공개`로 설정하면 공개일기 달력에 이모지가 뜨며, `[📖 모두의 이야기 모아보기]` 탭을 통해 다른 사용자들에게 일기가 공유되고 댓글로 소통할 수 있습니다.
4. **디데이 & 일정 관리**
   * 사이드바의 **[⏳ 디데이 추가]**에서 시험일, 여행 등 목표 날짜를 등록하면, **목표일 기준 2주(14일) 전부터 당일까지** 달력에 `D-14`, `D-13` ... `D-Day` 형태의 카운트다운 이벤트가 매일 자동으로 표시됩니다.
   * **[📅 일정 관리 달력]**에서 공부, 약속, 기념일 등 카테고리별로 일정을 등록해 색상별로 구분된 달력을 관리할 수 있습니다.

---

## ✨ 3. 주요 기능 설명 (Key Features)

* **🔐 보안 사용자 인증**: `bcrypt` 단방향 암호화 알고리즘을 적용하여 비밀번호를 안전하게 보호합니다.
* **📅 스마트 캘린더 & 디데이 시스템**: `streamlit-calendar`를 연동하여 비밀일기/공개일기 감정 이모지 노출, 카테고리별 일정 노출, 2주 전 실시간 디데이 카운트다운 기능을 제공합니다.
* **🎨 11종 멀티 테마 & 배경 customizer**: 드림코어, 포근함, 공주, 귀여움, 레트로, 다크 모드 등 11가지 테마 파레트와 에디터 전용 배경색 커스텀 기능을 탑재했습니다.
* **💡 오늘의 질문 릴레이**: 날짜별로 매일 새로운 질문이 제공되며 답변을 기록하여 자기 성찰의 시간을 가질 수 있습니다.
* **☁️ GitHub API 자동 영구 백업**: 앱에서 일기 작성/수정/삭제 시 `PyGithub` 라이브러리를 통해 SQLite3 DB 파일(`diary_app.db`)을 깃허브 저장소로 자동 커밋/업데이트하여 데이터 유실을 방지합니다.

---

## 🚀 4. 실행 방법 (How to Run)

1. 웹 브라우저를 통해 다이어리 서비스 접속 주소(또는 로컬 실행 주소)에 접속합니다.
2. 회원가입 또는 기존 계정으로 로그인하여 나만의 다이어리 메인 화면을 엽니다.
3. 상단 및 사이드바 메뉴를 통해 달력 확인, 일기 작성, 디데이 및 일정 관리를 자유롭게 이용합니다.
